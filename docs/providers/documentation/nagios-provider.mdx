## Connecting with the Provider

The Nagios provider allows you to receive alerts from Nagios monitoring systems within Keep.
It supports both Nagios XI (via REST API) and Nagios Core/XI (via webhooks).

## Supported Versions

- **Nagios XI**: Full support — API polling and webhooks
- **Nagios Core**: Webhook support via custom notification commands

## Setup

### Prerequisites

1. Access to a Nagios XI or Nagios Core instance
2. For API polling: a Nagios XI API key (found under your username in the Nagios XI web UI)
3. For webhooks: ability to configure notification commands on your Nagios server
4. Keep instance with webhook capability

### Configuration

The provider requires the following configuration for API polling (Nagios XI):

```yaml
authentication:
  host_url: "https://nagios.example.com/nagiosxi" # Your Nagios XI URL
  api_key: "your-api-key" # Nagios XI API key
```

### Webhook Configuration

To configure Nagios to send alerts to Keep via webhooks, create custom notification
commands. This works with both Nagios Core and Nagios XI.

#### 1. Host Notification Command

Add this to your Nagios configuration (e.g., `/usr/local/nagios/etc/objects/commands.cfg`):

```plaintext
define command {
    command_name    keep_host_notification
    command_line    /usr/bin/curl -s -o /dev/null -X POST \
        -H "Content-Type: application/json" \
        -H "X-API-KEY: $USER10$" \
        -d '{"type":"HOST","notification_type":"$NOTIFICATIONTYPE$","hostname":"$HOSTNAME$","host_address":"$HOSTADDRESS$","host_display_name":"$HOSTDISPLAYNAME$","host_state":"$HOSTSTATE$","host_output":"$HOSTOUTPUT$","long_host_output":"$LONGHOSTOUTPUT$","timestamp":"$LONGDATETIME$","notification_author":"$NOTIFICATIONAUTHOR$","notification_comment":"$NOTIFICATIONCOMMENT$"}' \
        $USER11$
}
```

#### 2. Service Notification Command

```plaintext
define command {
    command_name    keep_service_notification
    command_line    /usr/bin/curl -s -o /dev/null -X POST \
        -H "Content-Type: application/json" \
        -H "X-API-KEY: $USER10$" \
        -d '{"type":"SERVICE","notification_type":"$NOTIFICATIONTYPE$","hostname":"$HOSTNAME$","host_address":"$HOSTADDRESS$","service_desc":"$SERVICEDESC$","service_display_name":"$SERVICEDISPLAYNAME$","service_state":"$SERVICESTATE$","service_output":"$SERVICEOUTPUT$","long_service_output":"$LONGSERVICEOUTPUT$","timestamp":"$LONGDATETIME$","notification_author":"$NOTIFICATIONAUTHOR$","notification_comment":"$NOTIFICATIONCOMMENT$"}' \
        $USER11$
}
```

#### 3. Set Resource Variables

In your `resource.cfg` file:

```plaintext
$USER10$=your-keep-api-key
$USER11$=https://your-keep-instance/api/alerts/event/nagios
```

#### 4. Create a Contact

```plaintext
define contact {
    contact_name                    keep
    alias                           Keep Notification Contact
    service_notification_commands   keep_service_notification
    host_notification_commands      keep_host_notification
    service_notification_period     24x7
    host_notification_period        24x7
    service_notification_options    w,u,c,r,f,s
    host_notification_options       d,u,r,f,s
}
```

#### 5. Assign the Contact

Add the `keep` contact to your hosts and services, or to a contact group.
Then restart Nagios to apply changes.
